# NutriScan — КБЖУ блюд и продуктов

> Профессиональное Flutter‑приложение для мгновенного определения калорийности и БЖУ (белки/жиры/углеводы) любого блюда или продукта из магазина.

Введите название — приложение покажет калории, макронутриенты, состав калорий, диаграмму распределения и пищевую ценность на любой размер порции.

---

## Возможности

- **Быстрый поиск** на русском и английском (более 100 продуктов в встроенной базе).
- **КБЖУ** на 100 г — калории, белки, жиры, углеводы.
- **Регулировка порции** ползунком (10–500 г) с пресетами.
- **Круговая диаграмма** распределения макронутриентов и источника калорий.
- **Категории**: фрукты, овощи, мясо, рыба, молочка, крупы, выпечка, блюда, напитки, сладкое, орехи.
- **Избранное** и **история просмотров** с локальным хранением.
- **Светлая и тёмная темы** с переключением одним тапом.
- **Material 3 + Google Fonts (Inter)** — современный, чистый интерфейс.
- **Анимации** появления элементов через `flutter_animate`.

## Скриншоты экранов

Приложение состоит из четырёх вкладок:

| Главная | Поиск | Детали блюда | Избранное |
| ------- | ----- | ------------ | --------- |
| Категории, популярное, совет дня | Живой поиск + фильтр по категории | Диаграмма КБЖУ + слайдер порции | Сохранённые продукты |

- **Flutter 3.19+** / Dart 3.3+

## Запуск

```bash
flutter pub get
flutter run
```

Для сборки релизных артефактов:

```bash
flutter build apk --release          # Android
flutter build ios --release           # iOS
flutter build web --release           # Web
```

## Тесты

```bash
flutter test
```

В `test/food_database_test.dart` покрыты: поиск (RU/EN/частичный), целостность данных, фильтрация по категориям, масштабирование порций.

## База данных

Значения калорийности и макронутриентов взяты из открытых источников (USDA FoodData Central, российские таблицы химического состава продуктов). Все значения указаны на 100 г / 100 мл.

База находится в `lib/data/food_database.dart` и расширяется добавлением одной строки `FoodItem(...)`.
